# ASIC-Design-of-Fuzzy-Logic-Controller-for-Biomedical-Application

## Overview
This project focuses on the design and implementation of an **ASIC-based Fuzzy Logic Controller (FLC)** for biomedical applications. The objective is to develop a hardware-oriented fuzzy inference system capable of processing biomedical input parameters and generating reliable decision outputs with low latency and efficient resource utilization.

The controller was designed using **Verilog HDL** and verified through simulation to evaluate its functional correctness. The project demonstrates the implementation of fuzzy logic algorithms in digital hardware, making it suitable for future biomedical monitoring and diagnostic systems.

## Objectives
- Design a hardware implementation of a Fuzzy Logic Controller.
- Develop RTL modules using Verilog HDL.
- Implement fuzzy inference for biomedical decision-making.
- Verify the functionality through simulation.
- Explore ASIC design concepts for hardware-efficient computation.

## Technologies Used
- **HDL:** Verilog HDL
- **EDA Tools:** Cadence Virtuoso, ModelSim, Intel Quartus Prime
- **Domain:** ASIC Design, Digital VLSI, Biomedical Electronics

## Applications
- Biomedical Monitoring Systems
- Medical Diagnostic Devices
- Intelligent Healthcare Electronics
- Real-Time Embedded Systems
